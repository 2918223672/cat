/* ---------------- LCD 显示屏 (TFT 1.8" ST7735) ---------------- */
// LCD_CS        PB12    LCD 片选 (CS)
// LCD_D/C       PC5     LCD 数据/命令选择 (DC)
// LCD_BLK       PB1     LCD 背光 (BLK)
// (无独立RES引脚)

/* ---------------- 字库 IC (GT30L32S4W) ---------------- */
// ZK_CS         PD8     字库IC 片选 (CS)
// 字库 MISO = PB14 (SPI2_MISO，硬件SPI全双工读取)

/* ---------------- SPI2 总线 (LCD + 字库共用) ---------------- */
// SPI2_SCK      PB13    SPI时钟
// SPI2_MOSI     PB15    SPI主机发从机收
// SPI2_MISO     PB14    SPI从机发主机收 (仅字库用，LCD不接)
// LCD与字库通过各自的CS分时复用SPI2总线

/* ---------------- 编码器模块 (Encoders) ---------------- */
// ENC1_A        PA6     左编码器 A 相 (TIM3_CH1)
// ENC1_B        PA7     左编码器 B 相 (TIM3_CH2)
// ENC2_A        PD12    右编码器 A 相 (TIM4_CH1)
// ENC2_B        PD13    右编码器 B 相 (TIM4_CH2)

/* ---------------- 电机方向控制 (Motor Direction) ---------------- */
// motor_AO1     PC4     左电机方向控制 1 (AO1)
// motor_AO2     PB0     左电机方向控制 2 (AO2)
// motor_BO1     PD10    右电机方向控制 1 (BO1)
// motor_BO2     PD11    右电机方向控制 2 (BO2)

/* ---------------- 按键 (Keys) ---------------- */
// key_nev_white PA10    白阈值校准按键 (上拉输入)
// key_nev_black PA9     黑阈值校准按键 (上拉输入)

/* ---------------- 循迹传感器 MUX 控制 (Sensor MUX) ---------------- */
// track_bit0    PA8     模拟开关通道选择 bit0
// track_bit1    PC9     模拟开关通道选择 bit1
// track_bit2    PC8     模拟开关通道选择 bit2

/* ---------------- ADC 输入 (ADC1) ---------------- */
// ADC1_IN2      PA2     循迹传感器模拟输入 (ADC1通道2)

  ├──────┼──────────┼─────────────────────────────────────┼──────────────────────────────────────────────────────┤
  │ 7    │ 加 Kd    │ 小值起步                            │ pid.h 中 PWM_PERIOD = 100.0f 确认与实际 PWM 量程一致 │
  └──────┴──────────┴─────────────────────────────────────┴──────────────────────────────────────────────────────┘

  调参参考（你的电机）：

  PWM_PERIOD = 100.0f（对应 motor.c 里 pwm_duty*10，ARR=1050，实际占空比范围 0~1050）
  Kp: 0.5~1.5   → 响应速度
  Ki: 0.01~0.1  → 消除静差
  Kd: 0.0~0.05  → 抑制超调

  你在 pid.c:8-9 当前的初始化是：

  PID_Init(&left_pid,  1.0f, 0.01f, 0.1f);
  PID_Init(&right_pid, 1.0f, 0.01f, 0.1f);

  保持它，先跑起来再看。
